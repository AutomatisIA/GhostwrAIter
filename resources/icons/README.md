# Icons — placeholders

**Status**: Placeholder assets. To be replaced by a designer before the first public release.

## Why this directory exists

The `electron-builder` configuration in `package.json` references `resources/icons/icon.png` for every platform target (macOS, Windows, Linux). Without a committed icon file, the build command fails on a clean clone. This directory holds a minimum-viable placeholder so the build is reproducible from any environment.

## Current content

- `icon.png` — 512 × 512 PNG with the project's primary color (`#0EA5E9`) and a centered darker square where the LP lettering will go. Generated programmatically; not designer artwork. Used as the single icon source for all three platforms — `electron-builder` derives the platform-specific formats (`.ico` for Windows NSIS, `.icns` for macOS `.app`) from this PNG at build time when possible.

## Replacing the placeholder

Before the first public release, a designer should replace `icon.png` with a proper branded icon at 1024 × 1024 (electron-builder will downsample to every size the platforms need). If platform-specific icons are needed for fidelity, the designer can add:

- `icon.icns` for macOS (multi-resolution Apple Icon Image format)
- `icon.ico` for Windows (multi-resolution Windows Icon format)
- `icon.png` for Linux (high-resolution PNG)

Each referenced file in `package.json > build` must match one of the files in this directory.
